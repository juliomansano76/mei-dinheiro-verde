# MEI Finanças Verdes

Crie um PWA mobile-first de finanças pessoais para MEIs brasileiros. Use React + Tailwind CSS. A cor principal é emerald/green (#059669). O app deve ter 4 telas navegáveis por uma bottom navigation bar fixa: Dashboard (início), Lançamentos, Relatórios e Ajustes. Comece com o Dashboard contendo: saudação 'Olá, MEI', card verde com saldo do mês (receitas e despesas), barra de progresso do faturamento anual (limite R$ 81.000), alerta amarelo do DAS (dia 20), e lista dos últimos lançamentos. Todas as telas devem ter placeholder com empty state. A navegação deve funcionar trocando o conteúdo sem recarregar a página. Dados em localStorage por enquanto, sem backend.
